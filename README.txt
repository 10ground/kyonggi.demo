옷장 앱 — 로컬 제출용

실행: 압축을 풀고 index.html 또는 start-dashboard.bat을 더블클릭하세요.
Chrome 또는 Edge 일반 창을 권장합니다. Python/Node 설치, 서버, Google 로그인,
인터넷 연결이 필요하지 않습니다. 폴더 안 css, js 파일을 함께 보관하세요.

기능: 옷 등록·수정·제거·마지막 변경 취소, 사진 최대 4장,
검색, 분류/계절/색상 필터, 3D 옷장, JSON 데이터 백업/복원.
첫 실행 시 시연용 옷 100개가 생성됩니다. 기존 50개 버전을 열었던 브라우저에도
추가 샘플 50개가 자동으로 들어갑니다. 실제 Google 데이터는 포함하지 않았습니다.

저장 위치: 브라우저의 IndexedDB. 창을 닫았다 열어도 같은 브라우저에 남습니다.
다른 PC/브라우저/파일 경로에서는 저장소가 다를 수 있습니다.
브라우저 데이터 삭제 전, PC 이동 전에는 '데이터 백업 저장'을 누르세요.
제출할 때 본 폴더 전체와 필요한 백업 JSON을 함께 제출하세요.
제출받는 PC에서는 앱 실행 후 '백업 불러오기'로 데이터를 복원할 수 있습니다.
백업을 불러오면 현재 데이터가 교체됩니다. 백업에는 등록한 사진도 들어 있습니다.
시크릿/게스트 모드는 데이터를 보존하지 않을 수 있습니다.

구성:
index.html : 화면
css/style.css : 기존 디자인 (온라인 글꼴 의존 제거)
js/app.js : 기존 화면/검색/필터 로직 + 백업 버튼
js/local-store.js : 로컬 데이터/사진 저장
start-dashboard.bat : Windows 실행 도우미

기반: GitHub 10ground/clothing-inventory-app 최신 master 다운로드 (55dde5a).
사용자가 제공한 3d_cover_flow_wardrobe.html의 커버플로 배치·선택 방식을 통합했습니다.
별도의 3D 모델 파일 없이 JavaScript로 옷장과 서랍, 경첩, 봉을 구성합니다.
Unsplash 더미 사진 7장을 100개 샘플 항목에서 반복 사용합니다. PHOTO_SOURCES.txt 참고.
Google 토큰, 환경변수, Git 기록, 온라인 배포 코드는 포함하지 않았습니다.

3D 옷장 사용법:
- 분류별/계절별 버튼: 옷장을 180도 회전해 반대편 구성을 표시합니다.
- 상의/아우터/운동복 및 계절별 칸: 왼쪽 경첩을 축으로 문이 열립니다.
- 하의/가방/주얼리/신발: 서랍이 앞으로 열립니다.
- 칸 선택 후 봉이 나오고 카메라가 오른쪽 측면으로 이동해 왼쪽을 바라보며 커버플로로 연결됩니다.
- 드래그, 마우스 휠, 좌우 버튼 또는 키보드 방향키는 봉 위 옷의 위치만 이동합니다.
- 봉 위의 옷을 클릭하면 상단 옷이 바뀝니다. 상단 옷을 클릭하면 상세 화면이 열립니다.
- 샘플 옷은 사진 중앙에 큰 번호가 표시됩니다. 등록한 실제 옷 사진에는 번호가 붙지 않습니다.
- 오른쪽 세로 필터는 3D와 목록에 동일하게 적용됩니다.
- '옷장으로' 또는 뒤로가기로 닫습니다. Esc도 지원합니다.
- 시스템의 동작 줄이기 설정을 켜면 긴 회전/이동을 최소화합니다.
- WebGL을 사용할 수 없는 브라우저에서는 기존 목록으로 사용할 수 있습니다.

GitHub에서 노트북으로 옮기기:
- 이 폴더 전체를 비공개 GitHub 저장소에 올리고, 노트북에서 저장소 ZIP을 다운로드하거나 clone하세요.
- 압축을 푼 뒤 index.html 또는 start-dashboard.bat을 실행하면 시연용 100벌이 생성됩니다.
- 새로 등록하거나 수정한 옷은 브라우저 IndexedDB에만 저장됩니다. 그 데이터까지 옮기려면
  홈의 '데이터 백업 저장'으로 JSON을 따로 보관하고 노트북에서 '백업 불러오기'를 사용하세요.
- 백업 JSON에는 등록한 사진이 포함될 수 있으므로 공개 저장소에는 올리지 않는 편이 안전합니다.
